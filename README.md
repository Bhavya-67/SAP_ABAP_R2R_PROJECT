SAP ABAP R2R Accounting Report

Project Overview

This project demonstrates an SAP ABAP report for the Record-to-Report (R2R) accounting process. It retrieves accounting document information from SAP tables and presents the results using an ALV Grid.

Technologies

- SAP ABAP
- SAP FI (Financial Accounting)
- BKPF and BSEG tables
- SELECT statements and INNER JOIN
- SELECT-OPTIONS
- ALV Grid using "REUSE_ALV_GRID_DISPLAY"

Features

- Filter by company code
- Filter by posting date
- Filter by document type
- Display accounting document details
- Calculate debit amount, credit amount and difference
- Display results in ALV Grid

Selection Criteria

- Company Code: "S_BUKRS"
- Posting Date: "S_BUDAT"
- Document Type: "S_BLART"
